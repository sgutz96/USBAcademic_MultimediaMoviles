# **Desarrollo Móvil en Flutter - Curso Multimedia**

Este repositorio contiene los materiales y ejercicios correspondientes al curso de Desarrollo Móvil en Flutter. A lo largo del curso, se abordarán los conceptos fundamentales del desarrollo de aplicaciones móviles utilizando Flutter, cubriendo desde los principios básicos hasta el manejo avanzado de estado, APIs, persistencia de datos y despliegue de aplicaciones.

---

## **Estructura del Repositorio**

Este repositorio está organizado en carpetas correspondientes a cada una de las clases del curso. A continuación se describe cada clase y su contenido:

---

## **Tabla de Contenido de Sesiones**

| **Clase** | **Tema Principal**                 | **Descripción**                                                                                     |
|-----------|-------------------------------------|-----------------------------------------------------------------------------------------------------|
| **Clase 01** | **Introducción a Flutter**         | Configuración del entorno de desarrollo, estructura básica de un proyecto Flutter y primeros pasos.  |
| **Clase 02** | **Widgets Básicos**                | Uso de widgets esenciales como `Text`, `Container`, `Row`, `Column`, etc.                           |
| **Clase 03** | **Temas y Estilizado**             | Personalización de la apariencia de la aplicación con temas, colores, fuentes y estilos básicos.    |
| **Clase 04** | **Layouts Responsivos**            | Creación de interfaces que se adapten a diferentes tamaños de pantalla utilizando `Flex`, `Expanded`, etc. |
| **Clase 05** | **Navegación**                     | Manejo de rutas y navegación entre pantallas usando `Navigator` y `Routes`.                         |
| **Clase 06** | **Inputs y Formularios**           | Creación de formularios, validación de entradas y uso de widgets como `TextField`, `Form`, `DropdownButton`. |
| **Clase 07** | **Funciones y Lógica**             | Creación de funciones en Dart y la lógica básica para el funcionamiento de la app.                  |
| **Clase 08** | **Callbacks y Async/Await**        | Manejo de funciones asíncronas con `Future`, `Stream` y `async/await`.                             |
| **Clase 09** | **Estado Local**                   | Gestión del estado local con `setState` y otros métodos básicos para actualizar la UI.              |
| **Clase 10** | **Provider**                       | Introducción al patrón de gestión de estado `Provider` y uso de `ChangeNotifier` y `Consumer`.      |
| **Clase 11** | **Componentes Reutilizables**      | Creación de widgets reutilizables para mejorar la modularidad y escalabilidad de la app.            |
| **Clase 12** | **Listas y Builders**              | Implementación de listas dinámicas y eficientes con `ListView`, `GridView`, `ListView.builder`.      |
| **Clase 13** | **APIs y FutureBuilder**           | Consumo de APIs RESTful y uso de `FutureBuilder` y `StreamBuilder` para mostrar datos reactivos.    |
| **Clase 14** | **Manejo de Errores y Estados de Carga** | Implementación de manejo de errores y optimización de la UI durante la carga de datos.              |
| **Clase 15** | **Persistencia de Datos**          | Uso de `SharedPreferences`, `SQFLite` y técnicas para almacenar datos localmente en el dispositivo.  |
| **Clase 16** | **Compilación y Deployment**       | Proceso de compilación y despliegue de la app en Google Play Store y Apple App Store.               |
